
---
#### **Navegação e Edição Básica**

>[!quote] **Def**
> - **Ctrl + N**: Novo arquivo  
> - **Ctrl + O**: Abrir arquivo  
> - **Ctrl + S**: Salvar arquivo  
> - **Ctrl + Shift + S**: Salvar todos os arquivos  
> - **Ctrl + W**: Fechar aba/arquivo atual  
> - **Ctrl + Tab**: Alternar entre abas abertas  
> - **Ctrl + P**: Abrir pesquisa rápida de arquivos  
> - **Ctrl + G**: Ir para uma linha específica  
> - **Ctrl + F**: Localizar no arquivo atual  
> - **Ctrl + H**: Substituir no arquivo atual  
> - **Ctrl + Shift + F**: Localizar em todos os arquivos  
> - **Ctrl + Shift + H**: Substituir em todos os arquivos  
> - **Ctrl + /**: Comentar/descomentar linha ou seleção  
> - **Ctrl + Z**: Desfazer  
> - **Ctrl + Y** ou **Ctrl + Shift + Z**: Refazer  

---

#### **Manipulação de Texto**

>[!quote] **Def**
> - **Ctrl + X**: Recortar linha ou seleção  
> - **Ctrl + C**: Copiar linha ou seleção  
> - **Ctrl + V**: Colar  
> - **Alt + ↑/↓**: Mover linha ou seleção para cima/baixo  
> - **Shift + Alt + ↑/↓**: Duplicar linha ou seleção  
> - **Ctrl + D**: Selecionar próxima ocorrência da palavra atual  
> - **Ctrl + L**: Selecionar linha atual  
> - **Ctrl + Shift + L**: Selecionar todas as ocorrências da seleção atual  

---
#### **Gerenciamento de Janelas e Abas**

>[!quote] **Def**
> - **Ctrl + B**: Alternar visibilidade da barra lateral  
> - **Ctrl + **: Dividir editor  
> - **Ctrl + 1/2/3**: Navegar entre divisões do editor  
> - **Ctrl + Shift + P**: Abrir a paleta de comandos  
> - **Ctrl + `**: Abrir/fechar terminal integrado  

---
#### **Depuração**

>[!quote] **Def**
> - **F5**: Iniciar/continuar depuração  
> - **F9**: Adicionar/remover ponto de interrupção (breakpoint)  
> - **F10**: Passar por cima (step over)  
> - **F11**: Passar para dentro (step into)  
> - **Shift + F11**: Passar para fora (step out)  

---
#### **Extensões e Personalização**

>[!quote] **Def**
> - **Ctrl + ,**: Abrir configurações  
> - **Ctrl + K Ctrl + S**: Abrir atalhos de teclado (keyboard shortcuts)  

---
#### **Outros Atalhos Úteis**

>[!quote] **Def**
> - **Ctrl + Space**: Ativar sugestões de código (IntelliSense)  
> - **Ctrl + Shift + O**: Navegar por símbolos no arquivo  
> - **Ctrl + T**: Mostrar todos os símbolos no workspace  
> - **Ctrl + Shift + M**: Mostrar painel de problemas (problems)  

---

Esses são apenas alguns dos muitos atalhos disponíveis no VS Code. Você pode personalizar ou descobrir mais atalhos através da paleta de comandos (**Ctrl + Shift + P**) e procurar por "Preferences: Open Keyboard Shortcuts".
