#### **Comandos do Git**

```ad-quote
title: **Def**

O Git usa comandos para rastrear alterações: 
- (`git add`, `git commit`) 
  
Gerenciar diferentes versões do projeto: 
- (`git branch`, `git checkout`)
  
Colaborar com outros: 
- (`git push`, `git pull`) 
  
Iniciar um novo repositório: 
- (`git init`). 
  
Em resumo, os comandos do Git permitem controlar o histórico do seu código, trabalhar em paralelo e compartilhar suas alterações.
```
