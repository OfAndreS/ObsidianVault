#### **Intro ) -** Estrutura e Manipulação de Dados

```ad-quote
title: **Def**

**Summary:**

- SQL - Structured Query Language - é uma linguagem de domínio específico e declarativa considerada o padrão para gerenciamento e manipulação de bancos de dados relacionais RDBMS. Desenvolvida originalmente na IBM por Donald D. Chamberlin e Raymond F. Boyce no início dos anos 1970, SQL foi projetada para ser uma forma intuitiva e poderosa de consultar inserir, atualizar, definir e controlar o acesso aos dados.
```
