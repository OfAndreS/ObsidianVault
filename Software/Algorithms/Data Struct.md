#### **03 )** - Arrays e Listas Ligadas

> [!quote] **Def**
> **Summary:**
> - Arrays ou vetores são listas de tamanho fixo onde os elementos ficam lado a lado na memória física. Listas ligadas são correntes de dados onde cada pedaço de informação aponta unicamente para o endereço de memória do próximo item.

> [!quote] **Vault:** [[DS - Linear Structures]]

---

> [!done] _New_

#### **04 )** - Pilhas e Filas

> [!quote] **Def**
> **Summary:**
> - Pilhas funcionam como uma pilha de pratos reais onde o último objeto a entrar é o primeiro a sair da estrutura. Filas funcionam exatamente como uma fila de banco tradicional onde o primeiro a chegar é sempre o primeiro a ser processado pelo sistema.

> [!quote] **Vault:** [[DS - Analysis of Linear Structures]]

#### **05 )** - Tabelas Hash e Resolução de Colisões

> [!quote] **Def**
> **Summary:**
> - Tabelas Hash funcionam como uma agenda telefônica onde uma palavra chave leva direto ao resultado procurado na memória. Uma colisão acontece quando duas chaves diferentes tentam ocupar o mesmo espaço físico no sistema. Esse problema de espaço exige o uso de técnicas de resolução programática bem definidas.

---

> [!done] _New_

#### **06 )** - Árvores e Grafos

> [!quote] **Def**
> **Summary:**
> - Árvores são blocos organizados de forma hierárquica que lembram muito um organograma de empresa. As árvores binárias de busca são tipos específicos que aceleram muito a pesquisa de números. Grafos são redes de pontos interligados e servem para representar rotas de mapas ou conexões complexas de redes sociais.

#### **07 )** - Recursão

> [!quote] **Def**
> **Summary:**
> - A recursão ocorre quando uma função de código chama a si mesma para resolver um problema. Ela divide o desafio maior em subproblemas bem menores até encontrar um limite lógico de parada. Isso facilita muito o trabalho com problemas que possuem estrutura hierárquica como as árvores citadas na lição anterior.

#### **08 )** - Algoritmos de Busca

> [!quote] **Def**
> **Summary:**
> - Os algoritmos de busca são métodos práticos para localizar dados guardados no sistema. Eles podem olhar um item de cada vez sequencialmente ou usar inteligência matemática para dividir o espaço de busca pela metade. A escolha correta do método depende sempre do tipo de estrutura utilizada pelo programador.

> [!quote] **Vault:** [[DS Algoritmos de Busca]]

#### **09 )** - Algoritmos de Ordenação

> [!quote] **Def**
> **Summary:**
> - Os algoritmos de ordenação organizam conjuntos grandes de informações em uma sequência numérica ou alfabética bem definida. Existem métodos mais simples e lentos para conjuntos pequenos ou métodos bem avançados para organizar blocos gigantescos de dados de forma muito rápida.
