>[!tip] ### **Data Basic**

---
#### **Dado**

>[!quote] **Def**
>Um **dado** é a menor unidade de informação em computação. Ele representa um valor bruto, um fato ou uma entidade que, isoladamente, não possui significado claro ou contexto. Dados são a base para qualquer processamento computacional e podem ser de diversos tipos, como números, caracteres, strings, booleanos, entre outros.
>
>Um Dado nada mais é que um Registro + Estado
>
>Registro:
>- Unidade física capaz de armazenar informações binárias
>  
>Estado: 
>- Estado atual do Bit ( 0 ou 1 )

>[!quote] **Def**
>###### **Importância**
>
>Os dados são essenciais para qualquer sistema computacional, pois são a base para a criação de informações. Eles são coletados, armazenados e processados para gerar resultados significativos.

>[!quote] **Def**
>###### **Características de um Dado:**
>
>***Bruto***: 
>- Não possui contexto ou interpretação intrínseca.
>  
>***Atômico***: 
>- Representa uma única unidade de informação. 
>  
>***Tipos de Dados:*** 
>- Podem ser primitivos (inteiros, floats, caracteres) ou complexos (strings, estruturas, objetos).  

>[!quote] **Def**
>###### **Exemplos de Dados:**
>
>***01 )***: 
>- Número: `42`
>  
>***02 )***: 
>- Caractere: `'A'`
>  
>***03 )*** 
>- Booleano: `true`
>
>***04 )*** 
>- String: `"Estrutura de Dados"`

#### **Unidade de Armazenamento**

>[!quote] **Def**
>Uma **unidade de armazenamento** refere-se à forma como os dados são organizados e armazenados na memória de um computador ou em dispositivos de armazenamento secundário (como discos rígidos). Em Estrutura de Dados, a unidade de armazenamento é crucial para entender como os dados são acessados, manipulados e recuperados de forma eficiente.

>[!quote] **Def**
>###### **Importância**
>
>A escolha da unidade de armazenamento adequada é essencial para otimizar o uso de memória e o desempenho de algoritmos. Por exemplo, em uma **lista encadeada**, cada nó é uma unidade de armazenamento que contém um dado e um ponteiro para o próximo nó.

>[!quote] **Def**
>###### **Tipos de Unidades de Armazenamento:**
>
>***Bit***: 
>- A menor unidade de armazenamento, que pode representar `0` ou `1`.
>  
>***Byte***: 
>- Composto por 8 bits, é a unidade básica para representar caracteres ou valores numéricos pequenos.
>  
>***Palavra (Word)*** 
>- Conjunto de bytes que varia conforme a arquitetura do computador (ex: 4 bytes em sistemas de 32 bits ou 8 bytes em sistemas de 64 bits).
>  
>***Registro***: 
>- Agrupamento de dados relacionados que são tratados como uma única unidade. Por exemplo, um registro pode conter o nome, idade e endereço de uma pessoa.
>  
>***Bloco*** 
>- Conjunto de registros armazenados de forma contígua, frequentemente usado em sistemas de arquivos e bancos de dados.

#### **Informações**

>[!quote] **Def**
>As **informações** são o resultado do processamento, organização e contextualização dos dados. Elas representam dados que foram transformados em algo significativo e útil para quem os utiliza.

>[!quote] **Def**
>###### **Importância**
>
>As informações são o objetivo final do processamento de dados. Elas permitem que usuários e sistemas tomem decisões com base em dados organizados e contextualizados.

>[!quote] **Def**
>###### **Características de um Dado:**
>
>***Contextualizadas***: 
>- Possuem significado quando associadas a um contexto.
>  
>***Organizadas***: 
>- Estruturadas de forma lógica e coerente. 
>  
>***Úteis***:
>- Servem para tomar decisões ou realizar ações.

>[!quote] **Def**
>###### **Exemplos de Dados:**
>
>**Dados brutos**: 
>- `20` (idade), `8.5` (nota), `"Matemática"` (disciplina).
>  
>**Informação**: 
>- "Maria, de 20 anos, obteve a nota 8.5 na disciplina de Matemática."

#### **Aplicação em Estruturas de Dados**

>[!quote] **Def**
>###### **Exemplo de Unidade de Armazenamento:**
>
>***Armazenamento***: 
>- Dados são organizados em unidades de armazenamento (ex: registros, nós de uma lista encadeada).
>  
>Exemplo: 
>  - Em uma **árvore binária**, cada nó é uma unidade de armazenamento que contém um dado e ponteiros para os nós filhos. 
>
>---
>  
>***Processamento***: 
>- Dados são manipulados para gerar informações.
>
>Exemplo: 
>- Em uma **fila**, os dados são processados na ordem em que foram inseridos (FIFO - First In, First Out).
>
>---  
>  
>***Recuperação*** 
>- Informações são extraídas a partir dos dados armazenados.
>  
>Exemplo: 
>- Exemplo: Em um **banco de dados**, registros são consultados para gerar relatórios ou insights.
