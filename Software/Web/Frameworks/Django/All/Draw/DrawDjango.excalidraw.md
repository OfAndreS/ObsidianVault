01 ) HTML Forms ^f9BFJk7A

Para trabalhar com os Forms do Django primeiro é necessário entender como funciona o forms do HTML. ^Edb0SCTJ

A ) Tipos de Forms ^ZZ5qZZCY

Existem duas formas de se trabalhar com o Forms do HTML. A primeira instância é a modalidade padrão para 
o tratamento de dados padrões, tais como string, int, float. Já a segunda instância serve para tratar e enviar
"Arquivos" para o servidor.    ^VboaiHQt

C ) Atributos - Dados padrões ^M0ei4lgl

A estrutura padrão do cabeçalho de um forms para dados padrões é relativamente simples, contendo apenas dois
atributos ^nNRoThtd

<form action="http://foo.com" method="get"></form> ^egocj532

O atributo "Action" serve para direcionar a resposta. Enquanto o "Method" serve para informar o servidor qual é
a operação HTML que será executada. Em versões mais recentes do HTML o atributo "Action" pode ser deixado 
vazio, entretanto é uma boa prática manter o mesmo com um valor válido. ^HkXgpgyv

D ) Atributos - Dados Arquivos ^zG1RmiAW

B ) Funcionamento Base ^nAcjpApl

Diferentemente de outros atributos do HTML, o Forms necessita de um servidor para funcionar, ou seja, os dados
precisam que alguma aplicação esteja escutando no endereço fornecido para processar as informações enviadas através
do protocolo HTTP. Dessa forma, é possível enviar dados de uma forma simples e segura para o backend do projeto.  ^3Mnyh873
