````ad-quote
##### **Built In Function**
```

```ad-quote
title:

<p align="justify">As "Built-in functions", ou funções integradas, são um conjunto de funções pré-definidas e prontas para uso em uma linguagem de programação, sem a necessidade de importar bibliotecas externas. Elas oferecem funcionalidades essenciais e de uso comum, como manipulação de dados, operações matemáticas e entrada e saída de informações, otimizando e simplificando o desenvolvimento de software.</p>
```
````

````ad-quote
##### **1 ) Manipulação de Dados & Estruturas**
```

```ad-quote
title:
| Biblioteca | Descrição |
|---|---|
| `collections` | Tipos de dados avançados (`defaultdict`, `Counter`, `namedtuple`). |
| `itertools` | Funções para iteração eficiente (`product`, `permutations`, `combinations`). |
| `json` | Leitura e escrita de JSON. |
| `csv` | Manipulação de arquivos CSV. |
| `pickle` | Serialização de objetos Python. |
```
````

````ad-quote
##### **2 ) Sistema, Arquivos e Tempo**
```

```ad-quote
title:
| Biblioteca | Descrição |
|---|---|
| `os` | Interação com o sistema operacional (arquivos, pastas, variáveis de ambiente). |
| `sys` | Controle do interpretador Python (argumentos, saída, versão). |
| `shutil` | Operações avançadas com arquivos (copiar, mover, apagar). |
| `pathlib` | Manipulação de caminhos de forma orientada a objetos. |
| `datetime` | Trabalhar com datas e horas. |
| `time` | Funções de tempo e sleep. |
```
````
