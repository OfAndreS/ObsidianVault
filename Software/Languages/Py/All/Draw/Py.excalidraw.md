Multi-line strings  ^7tpiJQ36

O Python é uma linguagem que sempre preza pela legibilidade do seu código. Tendo isso em mente, muitas operações que foram planejadas para
ocorrer em apenas uma só linha podem se tornar maçantes de ler. Portanto, a feature que da vida ao Multi-line statement visa criar a possibilidade
do programador formatar a visualização de operações em múltiplas linhas visando melhorar a legibilidade do código.   ^zASHbY3A

Tipos de Multi-Line Statements suportados ^FFTBG7Zu
