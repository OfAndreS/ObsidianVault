#### **C++ iostream**

>[!quote] **Def**
>A biblioteca `iostream` é uma ferramenta poderosa e flexível para lidar com operações de entrada e saída em C++. Ela oferece uma sintaxe clara e segura, além de ser extensível para tipos de dados personalizados. Dominar o uso de `iostream` é essencial para qualquer programador C++.

>[!quote] **Vault:** [[C++ STD iostream]]

---
#### **C++ Containers**

>[!quote] **Def**
>Em C++, **Containers** são classes template da Standard Template Library (STL) projetadas para armazenar coleções de objetos ou tipos de dados. Eles oferecem maneiras eficientes e organizadas de gerenciar e manipular conjuntos de dados, como listas, vetores, conjuntos e mapas, simplificando a implementação de estruturas de dados comuns.

>[!quote] **Vault:** [[C++ STD Containers]]

---
#### **C++ Algorithms**

>[!quote] **Def**
>A STL Algorithms é uma coleção de funções genéricas em C++ que operam sobre contêineres, oferecendo operações comuns como ordenação, busca, transformação e contagem. Esses algoritmos são altamente eficientes e reutilizáveis, trabalhando com iteradores para manipular dados de forma consistente.

>[!quote] **Vault:** [[C++ STD Algorithms]]

---
#### **C++ Strings**

>[!quote] **Def**
>A `std::string` em C++ é uma classe da Standard Library projetada para manipular sequências de caracteres. Gerando a alocação de memória, fornece diversas funções membro para manipulação de strings (como concatenação, pesquisa, substring) e simplifica a gestão de texto em programas C++.

>[!quote] **Vault:** [[C++ STD Strings]]
