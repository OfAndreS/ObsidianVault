#### **Referência**

>[!quote] **Def**
>Referências em C++ são uma das características mais poderosas e úteis da linguagem. Elas permitem criar **aliases** (ou sinônimos) para variáveis existentes, oferecendo uma maneira eficiente e segura de manipular dados sem a necessidade de copiá-los. Neste guia detalhado, exploraremos todos os aspectos das referências em C++, desde conceitos básicos até usos avançados.

#### **Enum**

>[!quote] **Def**
>Enums (ou **enumerações**) e **enum classes** são estruturas de dados usadas em programação para definir um conjunto de valores constantes nomeados. Eles melhoram a legibilidade do código, evitam erros de digitação e garantem que apenas valores válidos sejam usados. Abaixo, vamos explorar esses conceitos em detalhes.
