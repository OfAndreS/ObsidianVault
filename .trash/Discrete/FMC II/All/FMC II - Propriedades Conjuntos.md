````ad-quote
##### **01 ) -** Definição de Conjunto e Pertencimento

```ad-quote
title:
Considere um objeto qualquer $x$ e um conjunto $A$. A relação básica entre elemento e conjunto é o pertencimento.
```
````

````ad-quote
title:

###### A ) - Relação de Pertencimento

```ad-quote
title:
Determina se um objeto formal faz parte ou não da coleção delimitada pelo conjunto.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $x \in A$ (_pertence_)
- $x \notin A$ (_não pertence_)
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in A$. Logo, o objeto $x$ valida todas as propriedades para integrar o conjunto $A$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $A = \{2, 4, 6\}$. Temos que $2 \in A$ e $3 \notin A$.
```
````

````ad-quote
##### **02 ) -** Subconjuntos e Inclusão

```ad-quote
title:
Considere dois conjuntos $A$ e $B$. A inclusão determina se um conjunto está contido dentro de outro.
```
````

````ad-quote
title:
###### A ) - Relação de Inclusão

```ad-quote
title:
Um conjunto $A$ é considerado subconjunto de $B$ se todos os elementos pertencentes a $A$ também forem elementos de $B$.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \subseteq B \iff \forall x (x \in A \implies x \in B)$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $A \subseteq B$. Logo, se $x \in A$, então $x \in B$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2\}$ e $B = \{1, 2, 3\}$. Como todo elemento de $A$ está em $B$, conclui-se que $A \subseteq B$.
```
````

````ad-quote
##### **03 ) -** Igualdade de Conjuntos

```ad-quote
title:
A igualdade entre dois conjuntos $A$ e $B$ baseia-se no princípio da extensionalidade, dependendo exclusivamente de seus elementos.
```
````

````ad-quote
title:

###### A ) - Identidade entre Conjuntos

```ad-quote
title:
Dois conjuntos são idênticos se, e somente se, possuírem exatamente os mesmos elementos, o que exige a dupla inclusão.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A = B \iff (A \subseteq B \land B \subseteq A)$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $A = B$. Diante de uma afirmação $x \in A$, pode-se substituí-la por $x \in B$ em qualquer linha argumentativa, e vice-versa.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{x \in \mathbb{R} \mid x^2 = 1\}$ e $B = \{-1, 1\}$. Como ambos possuem as mesmas entidades, então $A = B$.
```
````

````ad-quote
##### **04 ) -** Operação de Interseção

```ad-quote
title:
Considere os conjuntos $A$ e $B$. A interseção coleta a parte comum compartilhada pelas duas estruturas.
```
````

````ad-quote
title:

###### A ) - Elementos Comuns

```ad-quote
title:
É o conjunto constituído pelos elementos que pertencem simultaneamente a ambos os conjuntos originais.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cap B = \{x \mid x \in A \land x \in B\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in (A \cap B)$. Logo, pela disjunção entre conjuntos $x \in A$ e $x \in B$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2, 3\}$ e $B = \{2, 3, 4\}$. O conjunto resultante da operação será $A \cap B = \{2, 3\}$.
```
````

````ad-quote
##### **05 ) -** Operação de União

```ad-quote
title:
Considere os conjuntos $A$ e $B$. A união realiza a agregação total dos elementos de ambos.
```
````

````ad-quote
title:

###### A ) - Agrupamento de Elementos

```ad-quote
title:
É o conjunto formado por elementos que pertencem a pelo menos um dos conjuntos, admitindo o pertencimento a ambos.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cup B = \{x \mid x \in A \lor x \in B\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in (A \cup B)$. Para prosseguir na análise estrutural, deve-se obrigatoriamente abrir uma divisão de casos: Caso 1 ($x \in A$) e Caso 2 ($x \in B$).
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2\}$ e $B = \{3, 4\}$. O conjunto unificado resultante será $A \cup B = \{1, 2, 3, 4\}$.
```
````

````ad-quote
##### **06 ) -** Diferença de Conjuntos

```ad-quote
title:
Considere os conjuntos $A$ e $B$. A diferença remove do primeiro conjunto os elementos que fazem parte do segundo.
```
````

````ad-quote
title:

###### A ) - Exclusão de Elementos

```ad-quote
title:
É o subconjunto composto exclusivamente pelos elementos de $A$ que não se encontram presentes em $B$.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A - B = \{x \mid x \in A \land x \notin B\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in A - B$. Conclui-se imediatamente que $x \in A$ e $x \notin B$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2, 3\}$ e $B = \{3, 4, 5\}$. Retirando a interseção do conjunto $A$, obtemos $A - B = \{1, 2\}$.
```
````

````ad-quote
##### **07 ) -** Complementar de um Conjunto

```ad-quote
title:
Considere um conjunto universo $U$ e um subconjunto $A \subseteq U$. O complementar mapeia o que está fora do conjunto visado.
```
````

````ad-quote
title:

###### A ) - Conjunto Complementar

```ad-quote
title:
É a diferença entre o conjunto universo considerado e o subconjunto em questão.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A^c = U - A = \{x \in U \mid x \notin A\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in A^c$. Sabendo que o contexto se limita ao universo $U$, logo $x \notin A$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $U = \{0, 1, 2, 3, 4\}$ e $A = \{1, 3\}$. O complementar de $A$ em relação a este universo será $A^c = \{0, 2, 4\}$.
```
````

````ad-quote
##### **08 ) -** Conjunto das Partes

```ad-quote
title:
Considere um conjunto base $A$. O conjunto das partes constrói uma nova coleção cujos elementos são conjuntos.
```
````

````ad-quote
title:

###### A ) - Potência de um Conjunto

```ad-quote
title:
É a totalidade abstrata que abriga todos os subconjuntos possíveis que podem ser extraídos do conjunto original $A$.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $\mathcal{P}(A) = \{X \mid X \subseteq A\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, um conjunto $Y$ pertence às partes de $A$ ($Y \in \mathcal{P}(A)$). Transforma-se essa relação de pertencimento na relação de inclusão $Y \subseteq A$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $A = \{1, 2\}$. O conjunto contendo suas subdivisões será $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$.
```
````

````ad-quote
##### **09 ) -** Produto Cartesiano

```ad-quote
title:
Considere dois conjuntos $A$ e $B$. O produto cartesiano gera pares estruturados combinando elementos de ambos os conjuntos.
```
````

````ad-quote
title:

###### A ) - Conjunto de Pares Ordenados

```ad-quote
title:
É o conjunto de todos os pares ordenados onde a primeira componente origina-se de $A$ e a segunda componente origina-se de $B$.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \times B = \{(x, y) \mid x \in A \land y \in B\}$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, um par ordenado pertence ao produto cartesiano ($(x, y) \in A \times B$). Isola-se que $x \in A$ e, simultaneamente, $y \in B$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2\}$ e $B = \{a\}$. O resultado das combinações ordenadas será $A \times B = \{(1, a), (2, a)\}$.
```
````

````ad-quote
##### **10 ) -** Conjunto Vazio e Vacuidade

```ad-quote
title:
Considere o conjunto $\emptyset$, que possui a propriedade estrutural de não conter nenhum elemento.
```
````

````ad-quote
title:

###### A ) - Relação de Vacuidade

```ad-quote
title:
O conjunto vazio está contido em absolutamente qualquer conjunto, servindo como base trivial para provas de inclusão.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $\emptyset = \{x \mid \text{Falso}\}$
- $\forall A (\emptyset \subseteq A)$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese do teorema, um elemento pertenceria ao conjunto vazio ($x \in \emptyset$). Como a propriedade definidora do vazio exige a não existência de componentes, a afirmação colapsa imediatamente em um _absurdo lógico_, fechando o ramo da prova por contradição.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $A = \{x \in \mathbb{R} \mid x^2 < 0\}$. Como nenhum número real satisfaz a condição, então $A = \emptyset$.
```
````

````ad-quote
##### **11 ) -** Leis de De Morgan

```ad-quote
title:
Considere a negação das operações de interseção ou união sob a ação de um complementar.
```
````

````ad-quote
title:

###### A ) - Dualidade de Operadores

```ad-quote
title:
O complementar da união transforma-se na interseção dos complementares, e o complementar da interseção transforma-se na união dos complementares.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $(A \cup B)^c = A^c \cap B^c$
- $(A \cap B)^c = A^c \cup B^c$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \notin (A \cap B)$. Consequentemente, pela aplicação direta da equivalência lógica de De Morgan, extrai-se a disjunção de que obrigatoriamente $x \notin A$ _ou_ $x \notin B$, forçando uma divisão de casos na prova.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $U = \{1, 2, 3, 4\}$, $A = \{1, 2\}$ e $B = \{2, 3\}$. Temos $A \cap B = \{2\}$, logo $(A \cap B)^c = \{1, 3, 4\}$. O mapeamento individual gera $A^c = \{3, 4\}$ e $B^c = \{1, 4\}$, cuja união resulta em $A^c \cup B^c = \{1, 3, 4\}$.
```
````

````ad-quote
##### **12 ) -** Propriedade Distributiva

```ad-quote
title:
Considere a combinação simultânea das operações de união e interseção atuando sobre três conjuntos.
```
````

````ad-quote
title:

###### A ) - Distribuição de Operadores

```ad-quote
title:
A união distribui-se sobre a interseção, assim como a interseção distribui-se sobre a união, modificando o confinamento das variáveis.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
- $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, $x \in A \cap (B \cup C)$. Consequentemente, pela equivalência da propriedade distributiva, o elemento é transferido estruturalmente para a nova configuração, exigindo obrigatoriamente que $x \in (A \cap B)$ _ou_ $x \in (A \cap C)$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2\}$, $B = \{2, 3\}$ e $C = \{4\}$. Temos $B \cup C = \{2, 3, 4\}$. A interseção resulta em $A \cap (B \cup C) = \{2\}$. Computando o outro lado, $(A \cap B) = \{2\}$ e $(A \cap C) = \emptyset$, cuja união resulta em $\{2\}$.
```
````

````ad-quote
##### **13 ) -** Propriedade Associativa

```ad-quote
title:
Considere a aplicação sequencial de operadores de mesma natureza sobre uma cadeia de três conjuntos.
```
````

````ad-quote
title:

###### A ) - Agrupamento Invariante

```ad-quote
title:
A ordem de precedência dos agrupamentos internos não altera o resultado final da operação global, seja ela exclusivamente de união ou de interseção.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cup (B \cup C) = (A \cup B) \cup C$
- $A \cap (B \cap C) = (A \cap B) \cap C$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, os conjuntos estão confinados sob a forma $(A \cup B) \cup C$. Consequentemente, pela propriedade associativa, pode-se dissolver os parênteses originais para redefinir as fronteiras, escrevendo diretamente $A \cup (B \cup C)$ para simplificação algébrica.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1\}$, $B = \{2\}$ e $C = \{3\}$. O agrupamento $(A \cup B) \cup C = \{1, 2\} \cup \{3\} = \{1, 2, 3\}$, que preserva a identidade idêntica de $A \cup (B \cup C) = \{1\} \cup \{2, 3\} = \{1, 2, 3\}$.
```
````

````ad-quote
##### **14 ) -** Propriedade Comutativa

```ad-quote
title:
Considere a disposição posicional de dois conjuntos submetidos a um operador simétrico.
```
````

````ad-quote
title:

###### A ) - Permutação de Posição

```ad-quote
title:
A inversão na ordem dos fatores não modifica a estrutura interna do conjunto resultante nas operações de união e interseção.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cup B = B \cup A$
- $A \cap B = B \cap A$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, assume-se a validade de uma sentença baseada em $B \cap A$. Consequentemente, pela comutação dos termos, permite-se a substituição literal imediata pela expressão $A \cap B$ em qualquer linha subsequente da prova.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{a, b\}$ e $B = \{b, c\}$. A interseção calculada como $A \cap B$ resulta em $\{b\}$, valor idêntico ao obtido executando-se $B \cap A = \{b\}$.
```
````

````ad-quote
##### **15 ) -** Leis de Absorção

```ad-quote
title:
Considere a interação mista de união e interseção envolvendo repetição de um mesmo conjunto base.
```
````

````ad-quote
title:

###### A ) - Redução Estrutural

```ad-quote
title:
O conjunto externo absorve a operação interna por completo, reduzindo a expressão composta a um único termo isolado.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cup (A \cap B) = A$
- $A \cap (A \cup B) = A$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, a cadeia algorítmica da prova gerou o termo complexo $x \in A \cap (A \cup B)$. Consequentemente, pela aplicação da lei de absorção, colapsa-se a expressão redundante, deduzindo diretamente que $x \in A$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sejam $A = \{1, 2\}$ e $B = \{2, 3, 4\}$. A união interna gera $A \cup B = \{1, 2, 3, 4\}$. Calculando a interseção com o conjunto externo, temos $A \cap \{1, 2, 3, 4\} = \{1, 2\}$, que retorna exatamente ao conjunto $A$.
```
````

````ad-quote
##### **16 ) -** Regra da Adição Lógica

```ad-quote
title:
Considere uma proposição ou um fato de pertencimento estabelecido. A adição permite expandir o escopo lógico inserindo uma alternativa sem violar a verdade da premissa.
```
````

````ad-quote
title:

###### A ) - Introdução da Disjunção

```ad-quote
title:
Determina que se uma afirmação é verdadeira, a disjunção dela com qualquer outra afirmação também será necessariamente verdadeira.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $x \in A \implies x \in A \lor P$
- $x \in A \implies x \in A \cup B$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, o elemento cumpre $x \in A$. Consequentemente, pela regra da adição, deduz-se diretamente a disjunção de que $x \in A$ _ou_ $x \in B$, permitindo o salto imediato para a união de conjuntos.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $A = \{1\}$. Sabendo que $1 \in A$, infere-se por adição lógica que $1 \in A$ ou $1 \in B$, o que garante o pertencimento estrutural a $A \cup B$.
```
````

````ad-quote
##### **17 ) -** Regra da Simplificação Lógica

```ad-quote
title:
Considere uma conjunção lógica onde duas propriedades são válidas simultaneamente. A simplificação permite isolar uma das verdades.
```
````

````ad-quote
title:

###### A ) - Eliminação da Conjunção

```ad-quote
title:
Determina que a partir de uma afirmação composta onde ambos os fatores são verdadeiros, pode-se extrair qualquer um dos fatores de forma individual.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $x \in A \land x \in B \implies x \in A$
- $x \in A \land x \in B \implies x \in B$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, sabe-se que $x \in (A \cap B)$, o que se traduz na conjunção estrutural de que $x \in A$ e $x \in B$. Pela regra da simplificação, isola-se apenas o termo necessário para a continuidade da prova, como $x \in A$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Seja $x \in \{2, 4\} \cap \{4, 6\}$, significando que $x \in \{2, 4\}$ e $x \in \{4, 6\}$. Por simplificação, extrai-se diretamente que $x \in \{2, 4\}$.
```
````

````ad-quote
##### **18 ) -** Silogismo Disjuntivo

```ad-quote
title:
Considere uma disjunção entre duas proposições onde uma delas é comprovadamente falsa. O silogismo força a validade da alternativa restante.
```
````

````ad-quote
title:

###### A ) - Eliminação por Exclusão

```ad-quote
title:
Determina a eliminação de um caminho lógico quando a negação de uma das alternativas é estabelecida como um fato incontestável.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $(P \lor Q) \land \neg P \implies Q$
- $(x \in A \lor x \in B) \land x \notin A \implies x \in B$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese da linha argumentativa, tem-se a disjunção $x \in A$ _ou_ $x \in B$. Se uma linha analítica anterior provou categoricamente que $x \notin A$, aplica-se o silogismo disjuntivo para deduzir imediatamente que $x \in B$.
```
````

````ad-quote
title:
###### Ex ) Exemplo

```ad-quote
title:  
Sabendo que um número inteiro $n$ é par ou ímpar, se for demonstrado que $n$ não é par, conclui-se inevitavelmente pelo silogismo disjuntivo que $n$ é submetido à condição de ser ímpar.
```
````

````ad-quote
##### **19 ) -** Leis de Identidade e Dominação

```ad-quote
title:
Considere a interação de um conjunto qualquer com as estruturas extremas do sistema conjuntista: o conjunto vazio e o conjunto universo.
```
````

````ad-quote
title:

###### A ) - Fronteiras Triviais

```ad-quote
title:
Determina a anulação ou a preservação de expressões complexas quando operadas com elementos neutros ou dominantes.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $A \cup \emptyset = A \quad \text{e} \quad A \cap U = A$ (_identidade_)
- $A \cup U = U \quad \text{e} \quad A \cap \emptyset = \emptyset$ (_dominação_)
```

```ad-quote
title:
###### Uso da Hipótese
```
````

````ad-quote
###### A ) - Involução Conjuntista

```ad-quote
title:
A dupla negação do pertencimento a um conjunto anula o efeito das operações, retornando à identidade original da estrutura.
```

```ad-quote
title:
###### Definição Formal
```

```ad-quote
title:  
- $(A^c)^c = A$
```

```ad-quote
title:
###### Uso da Hipótese
```

```ad-quote
title:  
Por hipótese, a análise lógica determinou que $x \in (A^c)^c$, indicando que é falsa a afirmação de que $x$ não pertença a $A$. Pela involução do duplo complementar, elimina-se a dupla negação para estabelecer diretamente que $x \in A$.
```
````
