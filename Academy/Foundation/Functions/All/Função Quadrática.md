````ad-quote
##### **01 )** - Função Quadrática ou de 2º Grau

```ad-quote
title:
Uma função polinomial é conhecida como função do 2º grau, ou também como função quadrática, quando em sua lei de formação ela possui uma 'Função Polinomial' de grau dois, ou seja, $\mathrm{f(x)=ax^2+bx+c}$ em que a, b e c são números reais, e a ≠ 0. Além da lei de formação, essa função possui domínio e contradomínio no conjunto dos números reais, ou seja, f: R→ R.
```
````

````ad-quote
##### **02 )** - Valor numérico de uma função

```ad-quote
title:
Para encontrar o valor numérico de qualquer função, conhecendo a sua lei de formação, basta realizarmos a substituição do valor de x para encontrar a imagem $f(x)$.
```

```ad-quote
title:
###### ***Exemplos:***
```

```ad-quote
title:
Dada a função $f(x) = x² + 2x – 3$ calcule:
```

```ad-quote
title:
a ) 
1. $$f(0)$$
2. $$f(0) = 0² +2·0 – 3 = 0 + 0 – 3 = –3$$
```

```ad-quote
title:
b ) 
1. $$f(1)$$
2. $$f(1) = 1² + 2·1 + 3  = 1+2 – 3 = 0$$
```

```ad-quote
title:
c ) 
1. $$f(-2)$$
2. $$f(-2) = (-2)² + 2·(-2) – 3$$ 
3. $$f(-2) = 4  - 4 – 3 = –3$$
```
````

````ad-quote
##### **03 )** - Raízes da função de 2º grau

```ad-quote
title:
###### As soluções de uma equação do 2º grau 
```

```ad-quote
title:
<p align="justify">Conhecidas também como raízes da equação, são os valores de x que fazem com que essa equação seja verdadeira. Uma equação do 2º grau pode ter duas soluções reais, uma solução real, ou até mesmo nenhuma solução real. Para resolver se utiliza de dois métodos fórmula de Bhaskara e a operação soma e produto.</p>
```

```ad-quote
title:
<p align="justify">'Para resolver uma equação utilizando a fórmula de Bhaskara, calcula-se o discriminante, representado pela letra grega Δ'</p>
```

```ad-quote
title:
$Δ=b²−4ac$
```

```ad-quote
title:
'Com o valor do discriminante, é possível saber se a equação possui solução real e quantas soluções são:'
- Se Δ > 0, então a equação possui duas soluções reais.
- Se Δ = 0, então a equação possui uma solução real.
- Se Δ < 0, então a equação não possui solução real.
```

```ad-quote
title:
Além do discriminante, é necessário calcular o valor de _x_ pela fórmula de Bhaskara:
$x=\frac{-b\pm\sqrt{\Delta}}{2a}$
```
````

````ad-quote
title:
```ad-quote
title:
###### **Resolução por Soma & produto**
```

```ad-quote
title:
A operação soma e produto é um método mais intuitivo de resolução. Utiliza-se a soma e o produto quando as soluções da equação de 2º grau são os números inteiros $\text{Z}$ , pois, dada uma equação do 2º grau com soluções iguais a $x_1\text{ e }x_2$.
```

```ad-quote
title:
$$x_1+x_2=-\frac ba$$
$$x_1\cdot x_2=\frac ca$$
```

```ad-quote
title:
###### ***Exemplos:***
```

```ad-quote
title:
Quais são as raízes da equação $x² – 2x – 8 = 0$?
```

```ad-quote
title:
Primeiro, deve-se encontrar _a_, _b_ e _c_.
- a = 1
- b = -2
- c = -8
```

```ad-quote
title:
Substituindo os valores de _a_, _b_ e _c_ na fórmula:
$x_1+x_2=-\frac{(-2)}1=2$
$x_1\cdot x_2=\frac{-8}1=-8$
```

```ad-quote
title:
Agora, uma lista dos números inteiros em que a multiplicação será igual a -8
$1\cdot(-8) =-8$
$(-1)\cdot8 =-8$
$2\cdot(-4) =-8$
$(-2)\cdot4 =-8$
```

```ad-quote
title:
Dos números da lista, verifica-se o par de números cuja soma é 2.
$(−2)+4=2$
Note que esse par é o único cuja soma é igual a 2, então as soluções dessa equação são -2 e 4.
```
````

````ad-quote
##### **04 )** - Coordenadas do Vértice de uma Parábola

```ad-quote
title:
###### Para determinarmos os vértices de uma parábola 
```

```ad-quote
title:
Temos que encontrar o par ordenado de pontos que constituem as coordenadas de retorno da parábola. Esse ponto de retorno da parábola, mais conhecido como vértice da parábola, pode ser calculado com base nas expressões matemáticas envolvendo os coeficientes da função do 2º grau dada pela lei de formação $y = ax² + bx + c$.
```

```ad-quote
title:
O valor de $x$ na determinação do vértice de uma parábola é dado por
$$-\frac b{2a}$$
```

```ad-quote
title:
O valor de $y$ na determinação do vértice de uma parábola é dado por
$$-\frac\Delta{4a}$$
```

```ad-quote
title:
<p align="justify">Nesse caso, temos que, quando o coeficiente a for maior que zero, a parábola possui valor mínimo e quando a menor que zero, valor máximo.</p>
```
````

````ad-quote
##### **05 )** - Completar Quadrados

```ad-quote
title:
```ad-quote
title:
###### **Quando o coeficiente de x² é 1**
```

```ad-quote
title:
Temos uma equação do segundo grau e precisamos completar quadrados.
$$x^2+10x+24=0$$
```

```ad-quote
title:
<p align="justify">Nós completamos quadrados elevando metade do coeficiente do nosso termo $x$ ao quadrado, e somando o resultado aos dois lados da equação. Como o coeficiente do nosso termo $x$ é 10, metade dele é 5, que elevado ao quadrado é 25.</p>
```

```ad-quote
title:
$$x^2+10x + (25) +24 - (25) =0$$
```

```ad-quote
title:
Agora é só efetuar as operações algébricas e completar o trinômio quadrado perfeito.
$$(x+5)^2=1$$
```
````
