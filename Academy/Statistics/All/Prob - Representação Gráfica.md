>[!tip] ### **Tabela de Frequência**

---

```ad-quote
title: **Def**

Uma tabela de frequência (ou distribuição de frequência) é uma ferramenta estatística usada para organizar e resumir dados, mostrando quantas vezes cada valor ou intervalo de valores ocorre em um conjunto de dados. Ela é fundamental para análises descritivas e visualização de dados.
```

---
#### **Tipos de Tabelas de Frequência**

```ad-quote
title: **Def**

**a) Tabela de Frequência para Dados Discretos (não agrupados)**

* Usada quando os dados assumem valores específicos e distintos (ex.: número de filhos, notas em uma prova).
* Lista cada valor único e sua contagem.
```

```ad-quote
title: **Def**

**b) Tabela de Frequência para Dados Contínuos (agrupados em classes)**

* Usada quando os dados são contínuos ou têm muitos valores distintos (ex.: altura, peso, salários).
* Os dados são agrupados em intervalos (classes) e contabilizados.
```

```ad-quote
title: **Def**

**a) Frequência Absoluta (fi)**
* Número de vezes que um valor ou intervalo ocorre.

**b) Frequência Relativa (fr)**
* Proporção em relação ao total:
  $$fr = \frac{fi}{n} \quad (onde\ n = total\ de\ dados)$$

**c) Frequência Acumulada (Fi)**
* Soma das frequências absolutas até aquela classe.

**d) Frequência Relativa Acumulada (Fr)**
* Soma das frequências relativas até aquela classe.
```

```ad-quote
title: **Def**

O histograma é um gráfico estatístico usado para representar a distribuição de frequências de um conjunto de dados contínuos ou discretos agrupados em intervalos (classes). Ele é composto por barras verticais adjacentes, onde a altura representa a frequência (absoluta ou relativa) e a largura corresponde à amplitude do intervalo.
```
#### **Características do Histograma**

```ad-quote
title: **Def**

**Eixo X (horizontal)**: 
- Representa as classes (intervalos de valores).
  
**Eixo Y (vertical)**: 
- Representa a frequência (quantidade de observações em cada classe).
  
**Barras justapostas**: 
 - Sem espaços entre elas (diferente do gráfico de barras, que é usado para dados categóricos).
   
**Área proporcional à frequência**: 
- Quanto maior a barra, maior a concentração de dados naquele intervalo.
```
